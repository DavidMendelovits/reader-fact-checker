# Vendored skills

- `ponytail/` and `ponytail-review/`: copied unchanged from
  https://github.com/DietrichGebert/ponytail (commit ebd8654, MIT, see each
  folder's LICENSE). Used as a review gate on every PR: the smallest complete
  change, and a review that checks correct, safe, tested, lean.
- This repo marks a deliberate shortcut with a `ponytail:` comment that names
  its limit and when to revisit it. ponytail-review treats those as decisions,
  not findings.
